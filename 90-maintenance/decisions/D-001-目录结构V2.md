# D-001：目录结构 V2（学习/实践/实验/文献/维护 五区分离）

- **日期**：2026-11-19
- **状态**：已实施

## 背景

初始目录（theory / projects / experiments / weekly-reports / papers）只区分了内容类型，
没有区分"学习记录"与"项目维护"，也没有为错题、复习、考核留位置。

## 决策

采用五位数字前缀目录，按"用途"分区：

```
01-learning/     学习记录：notes / derivations / mistakes / review / assessments / reports / weekly
02-practice/     代码实现：01-micrograd … 06-benchmark-suite
03-experiments/  实验数据：templates / data / plots
04-papers/       文献笔记
90-maintenance/  项目维护：decisions / dev-notes / env / templates
```

## 理由

1. **两类工作分离**：学习是过程性记录（越写越多、允许混乱），维护是规范性文档（要精确）。
2. **数字前缀即流程**：学（01）→ 练（02）→ 验（03）→ 读（04），90 为支撑区。
3. **错题与复习独立成目录**：这是长期学习里最容易被混进笔记而丢失的部分。
4. **git mv 保留历史**：旧路径文件全部迁移，提交历史可追溯。

## 影响

- README、ROADMAP、LEARNING_RULES 中所有路径同步更新。
- 周报位置：`01-learning/weekly/`；实验模板：`03-experiments/templates/`。
