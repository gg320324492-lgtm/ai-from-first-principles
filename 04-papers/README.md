# 04-papers — 文献笔记区

> 论文阅读的笔记与追溯。**不上传论文 PDF 原文**（版权与仓库卫生，`.gitignore` 已排除），
> 只写自己的阅读笔记，并给出可查证的引用信息。

## 笔记规范

文件命名：`YYYY-MM-DD-论文短名.md`，如 `2026-11-25-attention-is-all-you-need.md`。

每篇笔记包含：

1. **引用信息**：标题、作者、年份、会议/期刊、arXiv 或 DOI 链接
2. **一句话总结**：这篇论文解决了什么问题
3. **核心方法**：用自己的话讲清关键机制（配公式）
4. **与课程的关系**：对应哪个阶段/项目，我为什么要读它
5. **我的疑问与评价**：哪里没读懂、哪里觉得可疑、可以怎么验证
6. **后续行动**：要不要复现、要不要对比其他论文
