# 01-learning — 学习记录区

> 这里只放"学习过程"的记录：理解、推导、错题、复习、考核、周报。
> **不放代码实现**（代码在 `02-practice/`），**不放实验数据**（数据在 `03-experiments/`）。

## 目录说明

| 目录 | 放什么 | 命名规范 |
|------|--------|----------|
| `notes/` | 概念笔记：按主题整理的理解、论文解读、名词解释 | `NN-主题/`（如 `01-neural-networks/`），文件 `YYYY-MM-DD-主题.md` |
| `derivations/` | 数学推导：自己动手推的公式，含推导过程与卡壳点 | `YYYY-MM-DD-主题-推导.md`，如 `2026-11-19-backprop-推导.md` |
| `mistakes/` | **错题本**：做错的推导、写错的代码、理解偏差，附订正 | `M-序号-主题.md`，如 `M-001-链式法则符号弄反.md` |
| `review/` | 复习记录：隔段时间重做错题/重推公式的结果 | `R-YYYY-MM-DD-复习范围.md` |
| `assessments/` | 考核记录：Tutor 出的理论题/代码题及作答、评分 | `A-阶段-第N次.md`，如 `A-阶段1-第1次.md` |
| `reports/` | 阶段总结：每个阶段结束的复盘报告 | `阶段N-总结.md` |
| `weekly/` | 周报：每周学习记录 | `week-XX.md`（模板：`TEMPLATE-week.md`） |

## 笔记写作原则

- 用自己的话写，不抄书；写不出来说明没懂，如实标注。
- 推导必须自己走一遍，卡壳的地方写进 `mistakes/` 或笔记的"疑问"栏。
- 每篇笔记结尾写 2–3 个自测问题，供复习时使用。
- 错题本条目必须包含：错在哪、为什么错、正确思路、防再错检查点。

## 与其他区的关系

- 笔记中提到的代码 → 链接到 `02-practice/` 对应项目
- 笔记中提到的实验 → 链接到 `03-experiments/` 对应实验
- 周报汇总本周所有笔记、代码、实验的进展
