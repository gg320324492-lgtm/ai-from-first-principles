# 03-experiments — 实验数据区

> 所有"跑出来的东西"都在这里：实验记录、原始数据、图表。
> 代码在 `02-practice/`；这里的重点是**可复现的实验档案**。

## 目录说明

| 目录 | 放什么 | 命名规范 |
|------|--------|----------|
| `templates/` | 实验报告模板 | `TEMPLATE-experiment.md` |
| `data/` | 原始结果数据（CSV/JSON/日志；大文件不入库） | `YYYY-MM-DD-实验短名/` |
| `plots/` | 图表（PNG/SVG） | `YYYY-MM-DD-实验短名-图名.png` |

> 实验报告 `.md` 直接放在 `data/YYYY-MM-DD-实验短名/` 内，与该实验的数据同目录，
> 或按周归入 `data/week-XX/`。二选一即可，保持一致。

## 一个实验的完整档案

```
03-experiments/data/2026-11-25-lr-schedule/
├── report.md          # 实验报告（用 templates/TEMPLATE-experiment.md）
├── config.json        # 超参数、种子、环境信息
├── results.csv        # 原始数据
└── (日志文件)
03-experiments/plots/2026-11-25-lr-schedule-loss.png
```

## 实验纪律

1. **先写假设再跑**：想验证什么、预期什么、什么算支持/否定。
2. **控制变量**：明确实验组与对照组，只改要研究的参数。
3. **记录种子与版本**：commit hash、依赖版本、硬件，保证能复现。
4. **保留失败结果**：负结果同样归档，不删除"不好看"的数据。
5. **结论对应数据**：结论只说数据支持的话；局限如实写。

## 复现检查

每个完成的实验，换一个时间重跑一遍，结果应一致（允许随机性则记录分布）。
无法复现的实验标记为"不可信"，不作为结论依据。
