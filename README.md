# AI From First Principles

**从底层原理到自主 Agent 系统** · 24 周系统学习计划

> 目标不是做一个聊天机器人，而是建立四项能力：
> 1. 理解大模型的数学与结构原理
> 2. 独立实现核心算法
> 3. 设计可靠的 Agent 架构
> 4. 通过定量实验评价 AI 系统

## 项目定位

- **学习周期**：24 周，每周 8–10 小时
- **知识主线**：LLM + Agent
- **学习方法**：理论 + 编程 + 实验
- **核心原则**：Agent 可以帮助完成工程工作，但不能替代掌握核心原理

## 每周学习流程（六步循环）

1. **理论学习** — 讲清核心概念、数学公式、必要前提与相关论文
2. **独立推导** — 自己解释原理、推导公式，Agent 只提供分层提示
3. **编程实现** — 先做最小可运行版本，再通过代码审查改进
4. **实验验证** — 单元测试、数值检查、对照实验、性能分析
5. **理解考核** — 理论题 + 代码题 + 实验分析题
6. **GitHub 归档** — 提交经过验证的代码、实验记录和总结

每周在 `01-learning/weekly/` 提交一份 `week-XX.md`。

## 阶段验收标准

每个阶段结束时逐条检查：

- [ ] 能够不用 AI 辅助解释核心原理
- [ ] 能够推导主要公式并说明假设
- [ ] 能够解释自己编写的关键代码
- [ ] 代码通过相应单元测试和数值检查
- [ ] 至少完成一组有明确结论的对照实验
- [ ] 将代码、实验与总结归档至 GitHub

## 设计原则

- **系统性**：从数学、模型、训练到 Agent 架构形成完整知识链
- **原理优先**：不以调用现成库代替理解关键机制
- **实验驱动**：每个重要观点尽可能配有可验证的代码实验
- **渐进实现**：先从零实现简化版本，再学习成熟框架
- **可复现**：重要实验必须有配置、代码版本、结果和结论
- **独立于正式科研项目**：使用教学数据和独立环境
- **持续迭代**：24 周是第一轮系统学习，完成后继续深入

## 环境要求

- Python ≥ 3.10
- 依赖见 `requirements.txt`（保持最小化，优先使用标准库与 numpy）
- 大模型权重、大型数据集、API 密钥一律不入库
- 环境快照存于 `90-maintenance/env/`

## 协作方式

1. **开始新一周**：根据 ROADMAP、已有进度和上周问题布置任务
2. **学习过程中**：Agent 辅助编程与实验，原理问题随时讨论
3. **阶段检查**：审查仓库内文件、提交和实验记录
4. **验收完成**：确认阶段成果后进入下一阶段

进度依据：`ROADMAP.md` + `01-learning/weekly/` + `03-experiments/data/`。
